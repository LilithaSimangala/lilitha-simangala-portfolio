Lilitha Simangala Portfolio

A responsive, static developer portfolio built with HTML, CSS, and JavaScript.

## Preview in VS Code

1. Open the portfolio repository folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension and choose **Open with Live Server**.

No package installation or build step is required. Google Fonts load from the internet; the page uses system fallbacks if they are unavailable.
